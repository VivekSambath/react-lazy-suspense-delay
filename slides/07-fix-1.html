…but it had two problems

🐢Slow widgets waited even longer

A widget whose code took longer than the 100 ms cap still suspended, just later. So React's 300 ms window started and ended later too. On a slow disk or busy machine, that widget could appear up to 100 ms later than with no wait at all.

⌨️Keyboard focus got lost

Modals now loaded on demand behind a spinner, and the spinner took keyboard focus. Closing Add widget no longer returned focus to the button that opened it. End-to-end tests caught it. The fix: preload those modals once the page is idle.
