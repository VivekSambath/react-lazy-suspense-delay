Making the files smaller changed nothing

The team made the files smaller twice. The widgets didn't appear any sooner either time.

✂️Cut ~100 KB from startup

A shared ~/ui index re-exported every modal (Add widget, Settings, Upgrade with pricing tables and card logos). Removing that re-export moved them off the startup path.

↩️Moved luxon out, then reverted

One helper pulled the luxon date library into the 283 KB main file. Moving it out made the file noticeably smaller, but nothing on screen changed, so the change was reverted.

So they profiled it (production build, headless Chromium)

Every script had loaded and run by ~100 ms. Then the browser sat idle, until several timers fired at once and the widgets rendered.

🎒It's like packing a lighter bag when the real hold-up is the bus timetable. Extension files load from local disk, so extra kilobytes cost very little.

The web version loads over the network, where bundle size matters more, but the throttle fix applies there too.
