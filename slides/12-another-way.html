Another way

No private fields? Keep your own pantry.

Skip React.lazy and keep loaded components in a module-level cache. Start the import early, show a placeholder until it arrives, then render with a normal state update.

  • Keep the loader stable across renders: define it once, at module level.
  • Handle failed imports: store the error and throw it during render, so an error boundary shows it.
  • Bonus: React.lazy keeps a failed import forever. This version can retry, e.g. when the widget remounts.
