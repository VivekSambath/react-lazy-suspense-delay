Takeaways

Four things to remember

These improvements shipped in Tab Widgets v2, and every widget uses the gate today.

⏱️

Measure when things appear

Not just file sizes. A smaller main file didn't change when anything appeared.

😴

Look for idle time

The biggest win came from a gap where the main thread did nothing.

📖

Know what your framework does on purpose

The 300 ms rule prevents flicker. But when content is ready almost at once (rendering from scratch, code from local disk), it was the largest single delay.

💻

Check lab results on real machines

Headless Chromium exposed the idle gap. Chrome on Windows confirmed the result.
