The problem

The food was ready. It just wasn't served.

Every new tab is a cold start: the dashboard builds itself from zero, every single time.

🗂️
0 ms
Tab opens
🍳
~100 ms
Widget code loadedthe food is cooked
😴 ~280 ms of nothing
🍽️
~380 ms
Widgets appearthe food is served

✗The guess: “our bundle is too big”

Shrinking the main bundle made no measurable difference.

!The real reason: React waits on purpose

A lazy component always suspends once, and React holds suspended content for 300 ms.

The fix removed no bytes. Rendering a placeholder directly, instead of suspending, showed the first widget ~240 ms sooner and most of the dashboard ~200 ms sooner.

~100 ms / ~380 ms measured in headless Chromium. Results measured in Chrome on a Windows desktop. The first version of the fix had to be rethought (slide 7).
